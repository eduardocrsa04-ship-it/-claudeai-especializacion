## ⚡ TRES COSAS CRÍTICAS QUE DEBES SABER

### 1. **Tu Claude Project es tu único punto de entrada**

Uno. Solo uno. El skill "especialista-ia" vive aquí y orquesta TODO.

- **NO** necesitas 3 projects
- **NO** necesitas documentos complejos afuera
- **SÍ** un Project centralizado + 5 skills especializados

**Por qué**: Economía cognitiva. Un lugar = claridad total.

### 2. **El skill "especialista-ia" es tu entrenador**

No es un skill para "hacer cosas". Es un skill para "guiarte a través del programa".

Cada sesión, lo usas así:
```
/sessión-nueva
[respondo 3 preguntas]
→ Yo estructuro 120 minutos
→ Trabajamos juntos
→ /entrega
→ Yo valido tu trabajo
→ Listo para día siguiente
```

**Por qué**: Estructura sin rigidez. Feedback inmediato. Escalamiento automático.

### 3. **Construcción real = aprendizaje real**

No es "leer sobre skills". Es "construir 1 skill por sesión, testearlo, documentarlo".

60+ minutos de cada sesión = manos en el teclado.

**Por qué**: Aprender haciendo es el único camino. Punto.
